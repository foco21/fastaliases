Aliases for Fastmail

Create an API token so the extension can make Masked Email aliases:

  1. In Fastmail, open Settings → Privacy & Security → Integrations → API tokens.
  2. Click New API token, give it a name, and choose Masked Email as the only scope.
  3. Copy the token and paste it below.

The token is stored only on this device, in the extension's private storage that web pages and content scripts can't reach, and is sent only to api.fastmail.com.
